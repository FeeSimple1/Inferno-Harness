Spellings normalized to INFERNO_Map_Reference.txt and
INFERNO_Lords_Reference.txt.  Where the printed board differs
from those references, the references control (see RECONCILIATION
NOTES at the end of this document).

Notation:
  (n)              = Numbered circle (force value = Stronghold Value)
  [LORDS: ... ]    = Lord/Vassal shields shown in the cell (composite
                     of all Lords and Vassals seated at that Locale,
                     except as noted under RECONCILIATION NOTES)
  CITY (red font)  = Major city as printed in red/large font in original
  [SUBMISSION]     = Result-marker cell with no named Locale (an "X"
                     over an Allegiance marker). Per RoP 1.4.2 SUBMISSION,
                     the rolling side must, if able, select a Stronghold
                     marked with Enemy Allegiance (only, not printed) that
                     is eligible for Revolt (1.4.1) and at or adjacent to
                     which the rolling side has a Lord cylinder; it Revolts.
                     [Corrected from an earlier "[SUBMISSION]" reading per
                     user adjudication 2026-05-20 — see RECONCILIATION NOTE G.]

Result-marker icons (Ghibelline? for the top table, Guelph? for the
bottom table) are omitted below for compactness.

==============================================================
RECONCILIATION NOTES & FLAGS
==============================================================

A. POPPI CELL (Table 1, R2C6) - Outpost-Vassal display anomaly.
   The cell shows Guido Guerra's shield plus shields associated with
   his Lombardia / Guelph League and Bologna Comune vassals.  Per
   the Map Reference, those vassals are seated at the Lombardia-
   Bologna East and West Outposts, NOT at Poppi.  Since Outposts
   never appear as Revolt Table results (1.4.1), the table appears
   to display those Outpost vassal shields at Guido Guerra's only
   non-Outpost Lord Seat (Poppi).
   - Confirmed: Pistoia Comune (Guido Guerra's third vassal,
     seated at Lombardia-Bologna West only) does NOT appear on
     the Poppi cell.  Only Lombardia / Guelph League and Bologna
     Comune are represented.

B. SIENA PODESTÀ APPEARS ON BOTTOM TABLE (Table 2, R1C5 Asinalunga).
   Rule 1.4.2 DESIGN NOTE states "Siena does not appear on the Revolt
   tables."  That note refers to Siena as a *Stronghold/Locale*
   result; the Siena Podestà's *shield* still appears at his
   secondary Lord Seat (Asinalunga), which is consistent with how
   other Lord shields appear at their Lord Seats throughout both
   tables.  No conflict.
   - Visually confirmed against the printed lord map.

C. PISA PODESTÀ APPEARS TWICE on the bottom table:
   - PISA itself (R1C1, his Main Seat)
   - Castiglione della Pescaia (R6C1, his third Lord Seat)
   This is the only Lord represented at two different result cells
   on the same table.  Consistent with the Map Reference's seat
   assignments.

D. SPELLING DEVIATIONS - printed board vs. project references:
   - Printed board: "Monte San Salvino"
     Map Reference:  "Monte San Savino"  -> using "Monte San Savino"
   - Printed board: "figline" (lowercase)
     Map Reference:  "Figline"           -> using "Figline"
   - Printed board: "Santa fiora" (lowercase 'f' on the lower table)
     Map Reference:  "Santa Fiora"       -> using "Santa Fiora"
   No other spelling deviations identified.

E. TERMINOLOGY - "Comune" vs "Commune":
   Per INFERNO_Lords_Reference.txt terminology note:
   - "Comune" (one m) = Commander's second mat (only Firenze and
     Siena have one)
   - "Commune" (two m's) = vassal type
   This document follows that convention.  E.g. "Prato Comune" (a
   Comune-style vassal of Firenze named with the Italian spelling)
   versus "Pisa Commune", "Massa Marittima Commune", "Grosseto
   Commune" (English-spelled vassal Communes).  These spellings
   match the Lords Reference verbatim.

F. NO ERRATA AFFECTS THE REVOLT TABLES.  The 10 April 2023 Official
   Errata makes no corrections to the Revolt Tables card itself.
   Rule changes from errata that touch the Revolt system
   (e.g. 4.5.1 deleting "Sacked" before "Stronghold") affect when
   Revolt is triggered, not the contents of the tables.

G. CROSSED-OUT CELLS ARE SUBMISSION, NOT NO-REVOLT (adjudicated).
   An earlier draft of this reference labeled the crossed-out
   faction-shield cells "[NO REVOLT] (no revolt possible)". RoP 1.4.2
   describes a SUBMISSION result ("If the table result shows an 'X'
   over an Allegiance marker, the rolling side must if able select a
   Stronghold marked with Enemy Allegiance ... at or adjacent to which
   the rolling side has a Lord cylinder. It Revolts."). Per user
   adjudication (2026-05-20), these 10 cells ARE the SUBMISSION result.
   The harness encodes them as SUBMISSION (a player-choice flip), not
   as no-ops. Logged in RULES_DECISIONS.md as Q-002.
