# Smoke Test Findings — Inferno Harness

Per-round log of probe-test discoveries (SMOKE-NNN). Each entry traces
a bug from detection through fix.

This file is the equivalent of the Nevsky project's
`SMOKE_TEST_FINDINGS.md` referenced in `FUTURE_PROJECTS_LESSONS.md`.
It will grow as phases land and probing begins. Empty at project start.

Format per entry:
- SMOKE-NNN sequential ID.
- Pattern (one of the 14 in `FUTURE_PROJECTS_LESSONS.md`, plus
  one-offs).
- Detection round / context.
- Symptom (1-2 sentences).
- Root cause (1-2 sentences).
- Fix commit hash.
- Regression test path (every SMOKE must have one).
